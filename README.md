# CariReps Site

Vercel-first prototype for the CariReps public website and early API layer.

## Stack

- Frontend: static HTML, CSS, and JavaScript
- Hosting: Vercel
- API: Vercel Functions
- Payments: Stripe
- Database later: Supabase or Neon
- Media later: Cloudinary

## Local Preview

```powershell
npm run dev
```

Then open:

```text
http://127.0.0.1:8080
```
