# CariReps Project Memory

## Positioning

CariReps connects growing US, Canadian, UK, and global businesses with elite Caribbean-based candidates, with a strong Jamaica talent focus. The brand should communicate quality, bilingual capability, workflow fit, productivity, and protected profit margins. Do not describe the offer as cheap labor.

## Public Language

- Use "Candidates" for public applicant-facing pages.
- Use "Clients" for businesses buying services.
- Use "Admin" for internal operators.
- Backend code may still use `talent` as a technical role, but public copy should prefer "candidate."

## Pricing

- Client platform access: $10/month.
- English Only candidate: $10 per candidate per month.
- Spanish Only candidate: $10 per candidate per month.
- Bilingual English & Spanish candidate: $12 per candidate per month.
- Minimum service duration: 1 month.
- Ongoing service renews month to month until cancellation is requested.
- Billing is prepaid. Any usage in a monthly cycle counts as a completed full month. No prorated refunds or partial credits.

## Required Candidate Capabilities

- Bilingual Support Capabilities
- Customer Success
- Sales & Revenue Growth
- Specialized Tech Support
- Social Media Management
- Onboarding & Integration
- Workflow Mapping
- KPI Definition
- Access Management
- Talent Matching
- Project Management
- Business + Creativity + Technology

## Automation Rule

Prefer rule-based internal agents first so core workflows run without AI-token dependency. Use AI later only for optional summarization, writing, or advanced recommendations.
