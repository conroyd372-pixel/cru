# CariReps Agentic Operating Model

## Core Rules

- Clients and talent use separate account paths.
- Clients pay platform access first, then select services, language tier, employee count, and duration.
- Talent applicants never hit the client paywall.
- Admin owns matching, assignment changes, promotions, billing exceptions, issue triage, and audit review.
- All operational messages stay inside CariReps. Direct email addresses and phone numbers are blocked and logged.

## Pricing Memory

- Platform access: $10 per client account per month.
- English Only agent: $10 per agent per month.
- Spanish Only agent: $10 per agent per month.
- Bilingual English & Spanish agent: $12 per agent per month.
- Minimum service duration: 1 month.
- Billing is prepaid. Any usage in a monthly cycle counts as a completed full month with no prorated refunds or partial credits.

## Internal Agents To Build

- Intake Agent: reviews client service requests and extracts required skills, language tier, employee count, duration, urgency, and tools.
- Matching Agent: recommends suitable talent based on skills, language capability, timezone, availability, utilization, and client needs.
- Billing Agent: checks Stripe subscription state, service duration, prepaid cycle status, discounts, trials, and renewal flags.
- Task Operations Agent: watches task schedules, completion updates, overdue work, and employee workload.
- Support Triage Agent: routes client and talent issue reports to admin with severity, affected user, company, project, and next action.
- Quality Agent: tracks client satisfaction flags, agent utilization rates, renewal risk, and performance notes.

## Skill Files To Preserve

- Pricing logic and prepaid billing policy.
- Role access model for admin, client, company admin, talent, and talent applicant.
- Message moderation rules for blocked email and phone sharing.
- Talent matching checklist.
- Promotion and discount approval checklist.
